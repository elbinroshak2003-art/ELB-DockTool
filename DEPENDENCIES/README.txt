# Python/Meeko dependency guide

For receptor preparation, configure a compatible Python 3.10+ environment and install/verify Meeko and its required dependencies. ELB-DockTool can auto-detect a compatible Python installation or use a configured interpreter.

Verify with:
`python --version`
`python -m meeko.cli.mk_prepare_receptor --help`

Third-party Python packages remain under their own licenses.
