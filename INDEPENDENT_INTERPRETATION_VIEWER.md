# ELB-DockTool Molecular Interpretation Viewer

The ELB-DockTool molecular interpretation viewer is independently implemented
using Microsoft WebView2 and 3Dmol.js.

3Dmol.js provides the molecular graphics/rendering layer. The ELB-DockTool
viewer interface, C# integration, docking-pose workflow, interaction analysis,
nearby-residue analysis, and export functions are part of ELB-DockTool.

3Dmol.js is a third-party component and remains under its own BSD 3-Clause
license. See the project's third-party notices for attribution and license
information.
