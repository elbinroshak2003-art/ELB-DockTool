PDBFixer / OpenMM notice
=========================

ELB DockTool does not bundle PDBFixer or OpenMM. At the user's request, the
application may use a locally installed Python interpreter to create an
ELB-managed virtual environment and install the published `pdbfixer` and
`openmm` packages from the configured Python package index.
